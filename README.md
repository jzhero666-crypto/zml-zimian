# ZML 字面

**丟歌、丟字幕，選個風格，一鍵做出文字 MV。**

ZML 字面是 [852話（hakoniwa）](https://852wa.com/) 的開源工具 [《JIZURA 字面》](https://github.com/852wa/JIZURA) 的**繁體中文改良版**。所有的排版、特效與輸出引擎都來自原作，謝謝原作者把這麼好的工具公開。

本改良版與原作者沒有合作關係，問題請不要回報給原作者。

## 怎麼用

用 Chrome 或 Edge 打開網頁，把歌曲（mp3、wav、m4a）、SRT 字幕、背景圖片或影片拖進去，按「生成 MV」。輸出固定 1080p、每秒 60 格。

詳細說明見網頁上的「圖解教學」和「說明書」。

## 改良了什麼

- 繁體中文介面，簡易模式三步驟就能做完
- SRT 字幕直接生成，歌詞時間照字幕
- ZML 精選風格與 21 套可營利使用的特殊字型，可以自己挑字型、加自己的字型
- 特效圖鑑：一千多種風格、字型、特效都能先看再挑
- 我的樣式：把挑好的一整套存起來，以後都照這樣
- 背景多張圖片與影片輪播、疊化字、鼓點震動、副歌呼應、好讀優先、中間留給角色、浮水印

## 隱私

歌曲、字幕、圖片、影片、字型、浮水印全部只在你的瀏覽器裡處理，不會上傳。
