ZML Poster 隱私權政策 / Privacy Policy

最後更新：2026-11-25 · Last updated: 2026-11-25

這是什麼 / What this is

ZML Poster 是音樂創作者 ZML 自己使用的發文工具，在 ZML 自己的電腦上執行，用官方 API 把 ZML 自己製作的短影音同時發佈到 ZML 自己的 YouTube、Instagram、Threads 與 TikTok 帳號。它不對外提供服務，沒有其他使用者。

ZML Poster is a personal publishing tool used only by the music creator ZML. It runs on ZML's own computer and uses the official APIs to publish ZML's own short videos to ZML's own YouTube, Instagram, Threads and TikTok accounts. It is not offered to anyone else and has no other users.

蒐集的資料 / Data accessed

工具只存取 ZML 本人授權的帳號，用途僅限：上傳影片、設定標題與說明、設定發佈時間、讀取發佈結果。不蒐集、不出售、不分享任何第三方的個人資料。

The tool only accesses the accounts ZML has authorized, and only to upload videos, set titles and descriptions, schedule publishing, and read back the publishing result. It does not collect, sell or share anyone else's personal data.

資料存放 / Storage

存取權杖只存在 ZML 自己電腦的本機檔案中，不會上傳到任何伺服器。影片在上傳時直接送往各平台的官方 API。

Access tokens are stored only in local files on ZML's own computer and are never sent to any other server. Videos are sent directly to each platform's official API.

Google / YouTube

本工具使用 YouTube API Services。使用時也適用 YouTube 服務條款 與 Google 隱私權政策。可隨時在 Google 帳戶權限頁 撤銷授權。

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time on the Google account permissions page.

撤銷與刪除 / Revocation and deletion

撤銷任一平台的授權，或刪除本機的權杖檔，即停止所有存取。工具本身不保留其他副本。

Revoking access on any platform, or deleting the local token files, stops all access. The tool keeps no other copies.
