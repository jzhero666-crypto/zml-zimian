ZML 字面　使用說明
==================

有圖的教學請開「圖解教學.html」；文字版的詳細說明在「說明書.html」（工具右上角也有「說明書」按鈕）。
裡面有：每個選項是什麼、怎麼把自己挑好的樣式存成「我的樣式」、字體怎麼挑怎麼加、
背景圖片和影片的規則、常見問題。

最快的用法
  1. 用 Chrome 或 Edge 開啟「開啟.html」（點兩下）。Firefox、Safari 不能輸出。
  2. 把歌曲拖進「歌曲」（mp3、wav、m4a）。檔名請取歌名。
  3. 把字幕檔拖進「字幕」（SRT 檔）。
  4. 把圖片或影片拖進「背景」，或按「黑底」「白底」。
  5. 選橫式或直式，按「生成 MV」。
  6. 看預覽。不喜歡按「換一版」，喜歡按「輸出 MP4」。

不知道特效長什麼樣
  按右上角的「特效圖鑑」。每個風格、字體、特效都有會動的小畫面，看了再打勾，
  挑好在圖鑑下面存成「我的樣式」。

注意
  · 「fonts」資料夾要和「開啟.html」放在同一個資料夾，特殊字型才會出現。
  · 你的歌、字幕、圖片只在這台電腦上處理，不會上傳。
  · 輸出固定是 1080p、每秒 60 格。輸出中不要關掉分頁。
  · 「我的樣式」和你加入的字型存在瀏覽器裡，換電腦或清除瀏覽資料會不見。
